# New project checklist

1. Copy this whole folder to the repository root and give it a URL-friendly name, such as `new-project`.
2. Fill in `_worksheet.md` first so the research and content stay organized.
3. Update the clearly named front-matter values at the top of `index.md`. The shared layout automatically creates the Week label, one-line title, and green accent.
4. Put project images in `assets/images`.
5. Add the new project link to the project list in the root `README.md`. The page navigation is automatic.
6. Duplicate the sample work section for each new entry.
