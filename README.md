## 01 / The process

**Observe → Ideate → Make → Test → Reflect → Repeat**

每次记录都尽量留下三个部分：我想探索的问题、实际做出的尝试，以及这次尝试如何改变了下一步的决定。草图、失败的版本和临时发现，都可以成为过程的一部分。

| Stage | What I will document |
| :--- | :--- |
| 💡 Ideation | Questions, references, sketches, and alternative directions |
| 🛠 Prototyping | Materials, quick experiments, and versions in progress |
| 🔍 Testing | Observations, feedback, and unexpected results |
| ↻ Reflection | What changed, what remains unclear, and what to try next |

## 02 / Open the notebook

点击下面的标题，试试展开和收起。这里先放示例提示，之后可以替换成每周的真实记录。

<details>
  <summary><strong>💡 Idea notes / 想法笔记</strong></summary>
  <p><strong>示例提示：</strong>我注意到了什么值得继续追问的现象？谁会遇到这个问题？</p>
  <p>这里可以记录几个不同方向，以及选择某个方向的理由。暂时没有答案的问题也可以留下。</p>
</details>

<details>
  <summary><strong>🛠 Prototype notes / 原型笔记</strong></summary>
  <p><strong>示例提示：</strong>如果只用纸、胶带和十分钟，我可以先验证哪一个想法？</p>
  <p>这里可以加入原型照片、制作步骤、材料选择，以及不同版本之间发生的变化。</p>
</details>

<details>
  <summary><strong>🔍 Reflection / 回顾与下一步</strong></summary>
  <p><strong>示例提示：</strong>实际发生的事情，和原本的预期有什么不同？</p>
  <p>这里可以记录观察和反馈，再写下一个具体的下一步：保留什么、改变什么、还需要测试什么。</p>
</details>
